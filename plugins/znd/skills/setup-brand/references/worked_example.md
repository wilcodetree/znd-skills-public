# Worked example: one filled-in result

ZeroNonsense.dev's own brand skill, condensed, as one example of the shape a finished answer can
take. It is public-facing brand identity, already visible on the live site, shown here for
structure and inspiration only. Build the new skill from the interview, never by copying these
values into someone else's brand.

---

Dark theme: background `#0A1422`, card `#112038`, band `#0E1B2E`, text `#EAF1F8`, muted text
`#8A9CB5`, accent `#3EDCB0`.

Light theme: background `#F6F8FA`, card `#FFFFFF`, band `#E9EEF4`, text `#0A1422`, muted text
`#4A5A70`, accent `#0B6B5B`, call-to-action fill `#0E5C4E`.

Print: white paper, `#0A1422` text, `#0E5C4E` as the single accent rule.

Type: one display face for headings, one workhorse face for body text, one monospace face for
labels, metadata and small eyebrow text.

Surfaces that get no theme, on purpose: a channel that strips inline styling anyway (many chat
and social platforms do this, so a themed version there is wasted effort), and a document that
gets printed and forwarded outside the brand's own tools, where consistent styling cannot be
guaranteed to survive.

Most often got wrong, numbered so an agent can check itself against the list:

1. The accent colour at low contrast is never used as text, only as decoration or a background
   tint. A colour that reads well as a logo fill can be illegible as body copy; check the actual
   contrast ratio, do not eyeball it.
2. A card and a background band cannot share one colour token even if they look similar, a card
   lifts off the page, a band recedes into it, and using the same token for both makes one of the
   two look like a mistake.
3. Any asset that implies an affiliation that does not exist (a former employer's mark on
   independent work, for instance) gets a variant with that mark removed, used everywhere outside
   that specific employer's own context.
4. A draft asset (an unfinished cut-out, a placeholder image) never ships. If a "final" version
   does not exist yet, say so rather than using the draft.

---

Notice the shape: exact values, not descriptions ("teal", "navy"); a short numbered list of past
mistakes rather than a long style essay; and an explicit statement of which surfaces get no theme
at all, which is often more useful than the theme itself.
