# Wait, what?

Wait. I do not understand where you have got to here. Re-pitch that.

- "That" is whatever lost me, which is usually more than the last message. Back up as far as
  needed, give the premise I was missing, then the point.
- Write the re-pitch in ASD-STE100 Simplified Technical English: one meaning per word, active
  voice, one instruction per sentence, sentences under 20 words, paragraphs under 6 sentences.
- Use the vocabulary the project already has: its own CLAUDE.md or AGENTS.md, and a GLOSSARY.md
  if one exists. No invented jargon, no acronym that is not in those files.
- If the conversation is in Dutch, apply the same rules in Dutch. Do not switch language.
- Shorter and clearer, not shorter and blunter. A re-pitch that only deletes words has failed;
  it must add the context that was missing.
- The TLDR-first house rule still holds: open the re-pitch with the point.
